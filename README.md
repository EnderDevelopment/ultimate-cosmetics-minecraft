# UltimateCosmetics

UltimateCosmetics is a premium cosmetic system for Minecraft servers, designed to enhance player experience with a wide range of customizable cosmetics. This plugin offers various categories of cosmetics, including wings and hats, with multiple styles and configurations to suit different preferences. It features an inventory-based GUI for easy access, permissions for access control, persistence to save player preferences, and administrator controls for server management.

## Install

1. Download the `UltimateCosmetics.jar` file from the [releases page](https://github.com/EnderDevelopment/UltimateCosmetics/releases).
2. Place the `UltimateCosmetics.jar` file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server to load the plugin.

## Use

1. Players can open the cosmetics menu by using the command `/cosmetics`.
2. Navigate through the inventory-based GUI to select and apply desired cosmetics.
3. Admins can manage cosmetics and permissions using the provided commands and configurations.
